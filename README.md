# ml-datascience-bildung

Dieses Repository dokumentiert meine **Lernreise im Bereich Data Science und Machine Learning**.
Da ich diese Themen von Grund auf lerne, sammle ich hier meine Notizen, kleine Projekte und Jupyter-Notebook-Experimente.

Das Ziel ist zu verstehen, **wie ein Data-Science-Projekt Schritt für Schritt aufgebaut wird** und warum bestimmte Methoden eingesetzt werden.

---

## Was ich in diesem Repository lerne

* Python Grundlagen für Data Science
* NumPy für numerische Operationen
* Pandas für Datenanalyse und Datenmanipulation
* Matplotlib und Seaborn für Datenvisualisierung
* Scikit-Learn für Machine-Learning-Modelle

* DBSCAN
